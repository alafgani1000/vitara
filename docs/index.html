✏️ Editing Content (Beginner)

Vitara is built using pure HTML5. You do not need any special software to edit the content.

How to Edit Text

  1. Open any HTML file (e.g., src/index.html) in a text editor (Notepad, Sublime Text, or VS Code).
  2. Press Ctrl + F (or Cmd + F on Mac) to search for the text you want to change, like "Vitara Healthcare".
  3. Replace the text with your own clinic's name.
  4. Save the file and refresh your browser.

How to Change the Logo

  1. The simplest way is to replace the text logo. Search for >VITARA< in the HTML header.
  2. To use an image logo, replace the logo text with an image tag:
    <img src="assets/img/your-logo.png" alt="My Clinic" class="h-8">

How to Change Images

We use high-quality Unsplash images via URLs for the demo. To use your own images:

  1. Place your JPG/PNG image inside the src/assets/img/ folder.
  2. Find the <img src="..."> tag in the HTML.
  3. Change the src attribute to point to your local image:
    <img src="assets/img/my-photo.jpg" alt="Doctor">

🎨 Changing Colors & Fonts

Vitara uses CSS Variables to control the main colors. You can change the entire color scheme of the template by editing just 4 lines of code!

  1. Open src/assets/css/vitara.css in your text editor.
  2. Look for the @theme block at the top of the file: 
@theme {
    /* Change these Hex colors to match your brand */
    --brand-primary: #1B3A2F;   /* Dark Green */
    --brand-secondary: #2C5545; /* Light Green */
    --brand-accent: #D4AF37;    /* Gold */
}

Important Note: Because Vitara uses Tailwind CSS v4, changing the variables in vitara.css requires you to recompile the CSS. Please see the Advanced section below.

⚙️ Advanced: Compiling CSS (Tailwind v4)

If you modify the CSS variables or add new Tailwind classes (e.g., text-red-500) to the HTML that weren't used before, you must compile the CSS so the browser can read the new styles.

Prerequisites

You must have Node.js installed on your computer.

Compilation Steps

  1. Open your Terminal (Mac) or Command Prompt/PowerShell (Windows).
  2. Navigate to the template folder: cd path/to/vitara
  3. Run this command to compile exactly once:
    npx @tailwindcss/cli -i ./src/assets/css/vitara.css -o ./src/assets/css/vitara.min.css
  4. Pro-Tip (Watch Mode): Add --watch at the end of the command while developing. It will automatically recompile every time you save an HTML file!
    npx @tailwindcss/cli -i ./src/assets/css/vitara.css -o ./src/assets/css/vitara.min.css --watch
